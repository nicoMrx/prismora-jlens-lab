Fast start

  1. Load the synthetic smoke-test experiment.
  2. Save and lock the protocol.
  3. Plan the matrix and execute three mock runs.
  4. Inspect, compare and bundle the evidence.

Evidence rule

A byte-identical canonical result under the same executable condition remains archived but is marked as non-independent. A locked protocol receives a SHA-256 identity. Exact backend response bytes are written once and never reserialized.

Current milestone boundaries

Implemented

Neuronpedia adapter, worker contract, matrix planning, preregistration lock, immutable storage, duplicate detection, cockpit, comparisons, filter replay, causal request builder, bundles.

Not yet a scientific GPU runtime

The bundled worker is deterministic synthetic data. Real open-weight execution requires a pinned model/J-Lens kernel behind the same worker API.
